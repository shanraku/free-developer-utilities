# Contributing

Thanks for helping improve this project.

- Open an issue before large changes or new tools.
- Keep tools accessible, responsive and dependency-light.
- Prefer browser-native APIs and local processing.
- Never transmit entered data without explicit informed consent and security review.
- Document edge cases, limitations and manual test steps.
- For standards changes, include primary source links and the date checked.
- Do not add trackers, hidden analytics, secrets or unexplained remote scripts.

Submit changes through a pull request.
