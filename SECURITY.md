# Security Policy

Do not publish exploitable vulnerabilities, secrets or private data in public issues. Use GitHub private vulnerability reporting for this repository if available; otherwise contact the maintainer privately through their GitHub profile.

Security principles:
- Browser-local processing by default.
- No collection or transmission of entered text.
- Use Web Crypto for security-sensitive randomness and cryptographic operations.
- Never treat encoding as encryption or plain SHA-256 as password hashing.
- Keep dependencies minimal and review external scripts.

Never submit real passwords, private keys, recovery phrases, tokens or confidential data in bug reports.
